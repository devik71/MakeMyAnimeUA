## 🚀 Нові можливості

### 1. Автоматичний вибір движка
```python
# Система сама обирає найкращий доступний движок
api = TranslationAPI()
result = api.translate_text("Текст", engine="auto")
```

### 2. Batch переклад
```python
# Оптимізований переклад списку текстів
texts = ["Текст 1", "Текст 2", "Текст 3"]
results = api.translate_batch(texts)
```

### 3. Моніторинг використання
```python
# Інформація про використання DeepL API
deepl_api = DeepLAPI()
usage = deepl_api.get_usage_info()
print(f"Використано: {usage['character_usage_percent']:.1f}%")
```

### 4. Централізована конфігурація
```python
# Всі налаштування в одному місці
config = get_config()
print(f"Debug: {config.debug_mode}")
print(f"Port: {config.port}")
```
